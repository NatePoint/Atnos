Atmos — это лёгкий, стильный и настраиваемый музыкальный плеер для повседневного прослушивания. Сочетает минималистичный интерфейс с мощными возможностями управления аудиотекой.

✨ Основные возможности
--------------------------------------------------------------
🎨 Глубокая кастомизация — меняйте тему, цвета, шрифты, прозрачность и поведение плеера под свой вкус.

🔊 Полный контроль — управляйте воспроизведением прямо из системного трея.

⚡ Высокая производительность — оптимизирован для быстрой работы даже с большими библиотеками.

📂 Поддержка плейлистов — удобная сортировка, поиск и управление треками.

🌓 Разные темы — автоматическое или ручное переключение.
--------------------------------------------------------------
🎧 Создано для тех, кто ценит музыку и удобство.
